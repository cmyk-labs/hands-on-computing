工作坊通讯

（1）先按原始顺序组织文字。多列排版让连续内容从一列流向下一列；列本身不是额外的 HTML 元素。

（2）调整窗口宽度，观察相同内容怎样重新分片。列数减少时，文字仍然完整保留，不需要复制成另一套内容。

下午的安排

（3）跨列标题将前后的文字分成两组。先读完标题前各列，再读标题和后面的内容。
