# CSS 课程补充协议

全局规则见[根协议](../../../AGENTS.md)，单元、代码块和图示格式见 [Notebook 协议](../../../docs/notebook-protocol.md)。范围见 [plan.md](plan.md)，实际环境见 [README.md](README.md)，风格参考 [CSS 编程规范](CSS编程规范.md)。

## 知识与机制

- 依据对应 W3C CSS 模块与 HTML 集成规范，MDN 辅助检索。说明模块、状态及实际支持条件，不用笼统的“CSS3”代替版本边界。
- 区分 HTML 属性、CSS 属性、属性值、选择器、描述符和 at-rule；说明层叠、继承、外边距折叠、包含块、层叠上下文、Flex 与 Grid 的实际成立条件。
- 本课程知识总览表只用于 CSS 属性；区分容器属性和项目属性，不将选择器、取值和属性混成一张清单。篇末来源表使用通用格式。
- HTML 名称按标签语义转义；CSS 选择器保留其原始语法，不将两种标记处理混用。
- 兼容性、特性查询和降级策略本身是主题时才展示相应分支；普通示例按已声明浏览器条件运行，不预置兼容包或防护样式。

## 展示与对照

- Notebook 使用 css 与 html 代码块，实际页面和样式表作为必要配套文件；不默认引入框架、构建工具、JavaScript 或 Python 包装。
- 对照示例保持无关条件一致，辅助样式与当前规则分清；不能用全局 reset 等样式掩盖正在观察的浏览器默认行为。
- 用开发者工具观察所需的计算样式、尺寸与布局结果；截图用于呈现效果，不能单凭外观推断层叠与布局原因。
- 路径说明区分外部样式表中的 URL 与内联样式所在页面的 URL 起点。

## 验收

- 核对目标浏览器中的实际结果，涉及响应式时检查所讲宽度，涉及焦点、悬停或状态时执行对应操作。
- 区分无效声明、有效但被覆盖、没有命中元素以及受布局条件限制；不把所有“没有看到效果”归为浏览器不支持。
- 样章与确认流程使用根协议，不要求每章重复申请确认；明确改变教学形式的任务按当前约定先提供代表性样例。
