# HTML 课程补充协议

全局规则见[根协议](../../../AGENTS.md)，Notebook 展示与引用格式见 [Notebook 协议](../../../docs/notebook-protocol.md)。范围见 [plan.md](plan.md)，浏览器和启动步骤见 [README.md](README.md)，风格参考 [HTML 编程规范](HTML编程规范.md)。

## 知识与组织

- 依据 WHATWG HTML、URL 与相关 WAI 官方资料；MDN 辅助解释与查找，不替代直接依据。
- 区分标签、元素、属性和属性值，区分字符引用与 URL 百分号编码；讲清结构语义和实际浏览器行为。
- 一个例子只增加当前知识点需要的结构。CSS 与 JavaScript 仅用于当前行为所必需的部分，不提前引入完整页面工程。
- 本课程的知识总览表只用于标签总览；属性、值与操作用短段落和条目，不把所有概念都做成表格。篇末参考来源表按通用协议保留，不受此限制。
- 正文中的 HTML 标签保留完整尖括号并正确转义，避免被渲染为实际元素。补充阅读可以链接既有讲解，但本章不能依赖其他章节的变量、页面或运行产物。

## 页面与资源

- Notebook 用 html 代码块展示源码，浏览器运行实际页面；不以 %%html、%%writefile 或 Python 启动包装代替 HTML 源码教学。
- 完整页面保留必要的文档声明和结构；片段明确其所在上下文，不为每个小片段复制整页模板。
- 页面文件头按通用源码要求使用 HTML 注释，不破坏文档声明位置；整页结果可集中说明，但局部交互的预期仍放在相关源码注释中。
- 区分磁盘路径、服务根目录和页面 URL；相对资源地址说明起点。服务启动入口在头部集中交代，不在每个知识点重复启动。
- 开发者工具只展示当前观察需要的结构或字段，截图不能替代对页面行为的解释。

## 浏览器验收

- 实际检查相关链接、片段导航、下载、新窗口、表单提交与键盘操作；按本章目标确定范围，不因页面能打开就判定交互通过。
- 表单约束验证等机制本身是主题时，明确展示有效与无效情况；普通页面不额外加入防御性 JavaScript 或输入拒绝层。
- 区分源码含义、浏览器默认行为与额外样式或脚本造成的效果；实际浏览器版本与未检查的差异在课程运行说明中记录。
