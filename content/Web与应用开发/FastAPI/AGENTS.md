# FastAPI 教学补充协议

本目录及子目录遵循[项目协议](../../../AGENTS.md)、[Notebook 编写协议](../../../docs/notebook-protocol.md)、[Python 编程规范](../../编程语言/python/Python编程规范.md)与 [FastAPI 编程规范](FastAPI编程规范.md)。课程范围见 [plan.md](plan.md)，环境与运行入口集中在 README.md。

- 每章独立提供完整示例与输入，只简列前置知识；不关联其他课程或依赖其他章节的配套文件。Notebook 的工作目录统一为本技术目录，脚本内基于自身位置定位资源时明确说明。
- 教学示例遵循根协议的正文优先与最小示例原则。先直接展示一条路由、一次调用或一个资源操作，再按本章目标逐步组合；不为每章统一创建 app、测试与服务管理器整套文件。
- 需要真实网络的实验，说明本地服务的启动与关闭方式；自动验收通过明确的就绪条件再发请求，设置有限等待并在 finally 中关闭资源。仅关闭客户端不算完成服务器清理。
- 应用内测试使用 TestClient 或 HTTPX ASGITransport；实际 Uvicorn 进程检查监听、请求和退出。生命周期、数据库、线程及异步资源的创建与清理按所用版本核查，测试替身不替代真实服务结论。
- 交互文档、跨域、上传、WebSocket、SSE 与模板须检查真实浏览器行为。小型浏览器页面只包含当前实验必要的 HTML 和 JavaScript，并分别参考对应编程规范。
- 同步与异步比较使用相同有限工作量，记录实际观察，不用固定耗时或固定加速倍数作成功条件。身份与权限实验使用本地测试用户及临时凭据，示例不记录真实密钥或令牌。
- 检查结果在当次交付说明报告，不在 Notebook 内增加验证记录。配套脚本的运行入口、输入与退出方式必须可由读者复现。
