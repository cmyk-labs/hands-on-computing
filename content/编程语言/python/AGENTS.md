# Python 教学与代码补充协议

适用于本目录及子目录。修改前读取[项目协作协议](../../../AGENTS.md)、[Notebook 编写协议](../../../docs/notebook-protocol.md)和 [Python 编程规范](Python编程规范.md)。

- 章节范围见 [plan.md](plan.md)，环境与依赖入口见 [README.md](README.md)。
- 编程规范是面向读者的独立文档，按 PEP 8、PEP 257 与官方文档整理，不写课程路径、环境、章节命令或内部约定。
- 课程说明和代码注释默认使用简洁中文，API 名称保留原文；多步骤主流程可用编号注释，单一操作不强行编号。
- 配套代码的固定路径使用一个完整相对字符串；变量只连接完整固定后缀，如 `base_dir / "data/reports/summary.json"`，并说明路径起点。
- 既有代码按各随章配置维护，不因官方规范整理而批量改动行宽或引号；Notebook 的结构、讲解、运行输出和引用遵循通用协议。
- 入门片段保留理解当前知识点所需的代码，不提前增加类型标注、类或工程包装；机制演示及反例须说明目的和成立条件。
- 涉及特殊 Python 版本、CPython 实现或第三方库时，分别核查对应来源和运行条件。
- 配套脚本、模块与测试参考同一份编程规范，课程特定要求以本文件和根协议为准；按本次改动检查真实运行，结果仅在交付说明中报告。
