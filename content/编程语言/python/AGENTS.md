# Python 课程补充协议

本文件只补充 Python 技术要求。全局教学、全部代码的最简原则、来源与验收范围见[根协议](../../../AGENTS.md)，单元格式和预期异常标记见 [Notebook 协议](../../../docs/notebook-protocol.md)。范围见 [plan.md](plan.md)，环境与命令见 [README.md](README.md)，语言风格参考 [Python 编程规范](Python编程规范.md)。

## 讲解边界

- 以对应版本的 Python 官方文档、标准库文档与 PEP 为依据；CPython 的字节码、内存管理、GIL 等实现行为明确标为实现细节，不写成所有 Python 实现的保证。
- 主线与特殊版本实验分开说明。自由线程、C 扩展等实验使用章节要求的版本与构建，不因编写普通章节而升级共同环境。
- 当前学习条件分支、异常、校验、命令行入口或上下文管理机制时，保留所讲机制的最小示例；其他章节不机械添加这些结构。
- 进程启动方式确实要求入口隔离时，解释入口条件与启动方式的关系，并保留最小必要结构；这不构成其他脚本统一添加入口保护的理由。

## 展示与检查

- 可直接运行的 Python 示例放 Code 单元；只有模块导入、打包、多进程、扩展等确需真实文件时才增加配套源码，不把 Notebook 变成脚本调用清单。
- 区分语法检查、导入成功、正常运行和预期异常。错误机制用独立示例展示原始异常，按通用协议核对异常类型及后续单元。
- 文件、线程、进程和扩展实验核对其实际副作用与资源退出；涉及序列化、操作系统或构建差异时写明条件，不用静默回退掩盖不支持。
- 已有脚本的专用配置按实际修改范围维护，不为统一样式批量改写与本次教学目标无关的文件。
