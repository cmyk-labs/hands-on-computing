# 学习分钟数打包示例

本目录是第 25 章的配套包，提供学习分钟数求和函数与 study-minutes
命令。输入为非负整数分钟数，命令至少接收一个值。

使用 Python 3.12 和统一的 hands-on-computing Conda 环境；依赖准备、
源码检查、临时构建与安装入口均见同章 Notebook。没有第三方运行依赖。

ci-example.yml 假定把本配套目录作为独立仓库根目录；当前仅供阅读，
没有启用远程工作流。
