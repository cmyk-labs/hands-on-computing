# JavaScript 课程补充协议

全局教学与代码原则见[根协议](../../../AGENTS.md)，单元和源码展示见 [Notebook 协议](../../../docs/notebook-protocol.md)。知识范围与标准基线见 [plan.md](plan.md)，实际工具版本和运行入口见 [README.md](README.md)，代码风格参考 [JavaScript 编程规范](JavaScript编程规范.md)。

## 知识与来源

- 语言结论定位到对应版本 ECMA-262，国际化内容定位到 ECMA-402；Node.js 与浏览器能力分别核对宿主官方资料。MDN 可辅助教学组织，不能代替规范确认版本与行为边界。
- 区分语言语义、引擎实现和宿主 API；明确标准版本、提案状态及实际支持条件，不以“ES6+”代替版本说明。
- 区分原始值、对象与属性，参数传递与对象变更，可迭代对象与迭代器，Promise 状态与结果，微任务与宿主任务。this、原型、闭包和异步顺序的结论必须带上决定行为的调用或运行条件。
- 类型、运算符与方法分别组织总览；方法说明返回值及是否改变对象，不把副作用和返回结果混为一项。

## 原生执行

- Notebook 用 javascript 代码块展示源码，实际执行原生文件；不通过 Python 包装、文件生成魔法命令或替代内核间接教学。
- 语言示例默认使用 Node.js 的 .mjs；涉及经典脚本、CommonJS、ES module 或浏览器上下文时明确区分。浏览器内容只增加必要页面和资源。
- 相互独立的示例在新进程或独立页面上下文运行；需要连续状态的示例放在同一脚本中并交代顺序。
- 工作目录、模块位置、import.meta.url 与页面 URL 分别说明；不能把这些路径起点当作同一位置。
- 有实际 npm 依赖时才维护课程 package.json、锁文件与运行命令；能用宿主内置功能完成当前目标时不引入额外框架。

## 异步与验收

- 条件分支、Promise 拒绝、try/catch、资源管理等机制按当前教学目标展示；普通例子直接暴露错误，不统一套 catch 或错误回调。
- 异步例子等待实际任务结束，检查顺序、结果和副作用；不靠随意延时把运行碰巧维持到输出出现。
- 实际创建的计时器、监听器、文件与进程按用途关闭；资源释放是当前流程的一部分，不扩展成通用兜底框架。
- 正常例子核对标准输出、退出状态和副作用；预期错误单独运行并核对原因，不全局忽略非零退出状态。浏览器示例实际检查页面及相关交互。
