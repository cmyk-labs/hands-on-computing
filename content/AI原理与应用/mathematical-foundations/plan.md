# 数学基础课程规划

学习目标：理解 AI 学习所需的数学对象、公式含义与成立条件，完成小型推导，并用 NumPy、SciPy 和图形观察核对线性代数、微积分、概率统计及数值计算中的结果。

前置知识：高中代数、方程与不等式、函数与平面坐标、基本三角函数；Python 变量、条件与循环、函数、模块导入和数组基本操作。各章所需的数学概念另列于下表。

归属：`content/AI原理与应用/mathematical-foundations/`。

当前状态：**已完成 28/28 章正文与空内核执行**。课程计划包含 **25 章主线、3 章扩展，共 28 章**。每行对应一份 Notebook，文件采用“二位序号-章节名称.ipynb”，例如 `01-数学符号与函数表达.ipynb`；章节链接见下表，实际版本与运行入口见 [README.md](README.md)。

## 范围与组织

主线从数学符号与函数表达开始，覆盖线性代数、矩阵分解、单变量与多变量微积分、矩阵求导与自动微分思想、概率与统计推断、信息量、数值稳定性及蒙特卡洛计算，最后完成数学建模综合实践，并以主成分分析（PCA）作为选学的数学连接例子。连续联合分布所需的简单二重积分在主线就地介绍；扩展补充一般积分区域与变量变换、贝叶斯推断与后验预测、马尔可夫链与 MCMC 采样。

课程以数学含义、成立条件、关键推导和小型计算为重点。数组与绘图库用于表达和检查数学对象；优化部分聚焦极值条件、凸性及约束的含义，算法族、求解器工程和运筹建模留给独立专题。主线采用实数、有限维向量与矩阵，涉及复数或其他条件时单独说明；不展开完整实分析、测度论、抽象代数及偏微分方程。

每章篇末提供一道重点练习的分层提示与独立参考解析，兼顾计算依据和条件判断；联合分布章另设分段阅读安排与自查点。

每章围绕明确任务，按“具体问题与小例子 → 定义和必要推导 → 数值或图形观察 → 条件与边界 → 综合应用和练习”组织。先解释当前公式中的符号、取值范围和维度，再写代码。相关概念合讲，只有学习目标不同才分章。

“必讲”包括表中的核心内容与边界；“选学”增加深度，不作为主线的隐含前提。扩展章节整体按需学习。代码和图形用于核对、展示与寻找反例，数学结论仍须有权威依据，有限次实验不代替证明。

## 教学呈现与实验成本

核心例子优先使用可手算的小向量、小矩阵、低维函数和有限概率表；综合实践才增加数据规模。推导保留关键步骤与条件，长证明按必要性作为选学内容，并明确哪些结论是在引用定理。

数学记号与代码形状分别说明，尤其注意数学列向量与一维数组、矩阵乘法与逐元素乘法、梯度方向与雅可比布局、总体量与样本估计量的对应。练习包含计算、条件判断、反例和方法选择，不只替换数值重复调用函数。

配图采用简洁、正式的科研风格：白底、统一字体、清楚的坐标与单位、色盲友好配色和整齐布局。几何图用于解释变换和投影，函数图用于展示局部变化，概率图用于区分数据分布与抽样分布。示意图注明用途，实验图来自实际计算，正文保存真实输出。

实验按普通 CPU 电脑设计，使用小型本地数据，无需 GPU、模型权重或付费服务。主要工具为 NumPy、SciPy 与 Matplotlib，沿用 `hands-on-computing` Conda 环境和现有 Python 3.12 基线。自动微分思想用手算与 NumPy 表达局部导数传递，不要求安装自动微分框架；PCA 选学也使用小型矩阵计算。实际安装版本、依赖检查和运行步骤集中在 [README.md](README.md)，直接依赖见 [requirements.txt](requirements.txt)。

首次编写从基础样例开始，确认符号解释、推导深度和代码观察的节奏后逐章展开。每章独立提供输入，Notebook 工作目录为本课程目录；仅在实际需要时增加配套文件，格式遵循 [Notebook 编写协议](../../../docs/notebook-protocol.md)，代码参考 [Python 编程规范](../../编程语言/python/Python编程规范.md)。

- 数学解释可追溯到直接支持该内容的一手来源；定义、定理、推导与实验观察分清，公式中符号、维度和成立条件完整。
- 代数与微积分示例同时核对可手算结果、形状、残差或近似误差；差分、求积和矩阵计算的容差结合输入规模与数值条件说明。
- 概率与统计示例核对归一化、支持集、独立性或抽样假设；记录随机种子、样本量与重复次数，区分理论值和实际观察。
- 从空内核顺序执行并保存真实输出；图形和导出结果检查字体、单位、图例、误差表达及实际阅读尺寸下的可读性。
