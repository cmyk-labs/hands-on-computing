# 数学基础教学补充协议

适用于本目录及子目录。编写前读取[项目协议](../../../AGENTS.md)、[Notebook 编写协议](../../../docs/notebook-protocol.md)和 [Python 编程规范](../../编程语言/python/Python编程规范.md)。章节范围见 [plan.md](plan.md)，环境与运行见 [README.md](README.md)。

- 教学风格与 Python 课程一致。编写前对照[内置类型与运算](../../编程语言/python/02-内置类型与运算.ipynb)和[容器与对象引用](../../编程语言/python/04-容器与对象引用.ipynb)：短段讲解后接最小代码，必要边界就地说明，结果解释写在代码注释中，综合应用置于基础讲解之后。
- 每章按规划覆盖必讲定义、条件、关键推导和实践；选学明确标识，不成为主线隐藏前提。前置知识只列具体概念或操作，不要求先读其他章节。
- 开篇依次单列“学习目标：”“前置知识：”“运行环境：”“环境准备：”“工作目录：”。环境准备链接 README.md，工作目录写“本 Notebook 所在目录；重启内核后从上到下运行”。
- 主知识点使用连续编号二级标题；必要子节使用对应三级标题。正文不使用行内代码高亮；术语或 API 总览表逐行保留原文名称和“中文名称／含义”。
- 先用可手算的小例子说明用途，再写定义、必要推导和代码观察。主线默认实数和有限维对象，其他条件单独说明。数学公式使用标准 Markdown 数学排版，不借助自定义 CSS。
- 符号首次出现就说明含义、范围、维度与必要单位；明确向量布局、矩阵形状、求和范围、定义域和抽样条件。区分数学列向量与一维数组、逐元素运算与矩阵运算、梯度与雅可比布局。
- 定义、引用定理、关键推导与数值观察分清；关键代数步骤不能只用库调用代替。有限次模拟和小误差不作为数学证明，解释必须有写作前核查的一手依据。
- 每章独立提供导入和小型输入，固定路径用完整相对字符串；不依赖其他 Notebook 的变量或文件。正文优先使用 Code 单元，不建立无必要的配套工程。
- 用 print() 展示数值与数组观察，图形使用 plt.show()。每处输出旁的注释写明预期值或图形特征，必要时补充核对方法；数值误差和模拟结果按通用七条原则区分量级、本次样本与理论值。不添加打印解释器或环境版本的教学单元。
- 实数计算按输入尺度和问题条件解释容差；方程检查残差，分解检查重构与正交性，差分检查步长，积分检查区间、间距与误差。不要仅以“没有报错”判断结论正确。
- 概率实验说明支持集、参数、样本量、重复次数与抽样假设，使用局部 Generator 和固定种子；区分理论量、估计量和某次样本的估计值。教学模拟须明确标识。
- 图形采用白底、统一文字层次、清楚标签和色盲友好配色；几何图使用适当纵横比。每图有明确观察目的，检查裁切、图例、单位和误差含义；图形标签可使用英文或数学记号并在正文解释。
- 辅助学习示意图放在 `image/illustration/`，实际成图与截图放在 `image/`；Notebook 图形输出不要求另存。制作、编号、扩展名与跨章复用遵循[通用图示要求](../../../docs/notebook-protocol.md#图示的制作与整合)。
- 练习逐题采用“题目 Markdown → Code”，保留必要输入和注释占位，不主动报错。兼顾计算、预测、条件判断和方法选择，至少一题改变假设或增加约束并要求解释。
- 最后一个单元为“## 参考与引用来源”，采用“网站／本章参考内容与定位”两列表格，按网站去重并保留具体小节、版本或页码。数学依据与 API 依据分别核查，不把 API 文档当作超出其内容的定理证明。
- 每章先在本地草稿确认样板，来源核查、空内核执行和图形检查后整理进本目录；真实输出随正文保存，检查结果只在交付中报告。
- 并行按单章排队；同一 Notebook 只有一名编写者，完成并验收一章即补下一章。协调者统一维护计划、环境、依赖及总目录。
