# pandas 教学补充协议

适用于本目录及子目录。编写前读取[项目协议](../../../AGENTS.md)、[Notebook 编写协议](../../../docs/notebook-protocol.md)及 [Python 编程规范](../../编程语言/python/Python编程规范.md)。章节范围见 [plan.md](plan.md)，环境与运行入口见 [README.md](README.md)。

- 第 01 章[Series与DataFrame](01-Series与DataFrame.ipynb)的教学写法已获用户确认，后续章节以该样例为基准，按 plan.md 推进。每章独立提供完整输入与导入，不读取其他 Notebook 的变量或运行产物。
- 并行任务按单章分配，各章完成来源核查和空内核执行后交回审校，完成一章即补入下一章；同一 Notebook 只由一个编写者修改。计划、环境说明、依赖与总目录由协调者统一更新，避免并行覆盖。跨课程顺序见[项目方案](../../../docs/project-plan.md)。
- 按 plan.md 中的必讲、边界和选学范围组织内容；基础验收覆盖必讲与边界，不将选学机制作为后续主线的隐藏前提。
- 教学写法与现有 Python 入门章节保持一致，采用简洁的概念或操作标题，直接说明含义、用法与必要条件，压缩重复铺垫；不因精简而省略标签、类型、形状或版本边界。
- 先用常见输入完成一个可理解的任务，再介绍替代输入、其他 API 与机制；不同写法各说明适用场合，避免连续罗列构造方式。围绕同一任务可复用一张小表完成短流程，明确变量来源；独立知识点就地提供输入，综合任务放在“综合应用”中。
- 开篇依次单列“学习目标：”“前置知识：”“运行环境：”“环境准备：”“工作目录：”，工作目录写“本 Notebook 所在目录；重启内核后从上到下运行”。额外输入或运行条件仅在实际需要时补充。
- 练习逐题安排“题目 Markdown 单元 → Code 单元”，提供必要输入、待预测语句或填写注释；检查标准与必要提示写在代码注释中，不用未定义名称或主动报错占位。预测题不在待预测语句旁给出答案。
- 练习兼顾操作、预测和方法选择；至少一道题改变任务条件或增加约束，要求解释选择理由。优先改造现有题目，不只更换数字或增加 API。
- 篇末来源统一使用“网站／本章参考内容与定位”两列表格，同一网站一行，保留版本、直接链接和必要小节定位；写作前逐项核查。
- Notebook 工作目录统一为本课程目录；固定文件路径使用完整相对字符串，变量只连接完整固定后缀。小表优先在单元内构造，必需资源才放入 `scripts/二位序号-英文主题/`。
- 使用 `import pandas as pd`，确有数组计算时再导入 NumPy。先展示几行数据和具体操作，再讲对齐、复制和类型机制，不以长链式表达式引入基础主题。
- 按通用协议用 print() 展示结果，info() 等自行输出的方法可直接调用；表格说明写在注释中，指出关键行列、dtype、索引和缺失值，不复制全部输出。
- 按 pandas 3 行为编写；链式赋值、Copy-on-Write、默认字符串及分类分组参数须核对官方版本。不以关闭警告或修改全局选项掩盖行为差异。
- 选择、赋值、合并、重塑和分组示例同时检查值、标签、顺序与结果形状；涉及键关系时核对唯一性、未匹配项和连接前后行数。
- 采样实验记录输入顺序、参数和 random_state；流程复现从相同原始输入开始。仅对明确约定的去重、规范化等步骤检查幂等性，不要求所有数据变换重复作用于结果后仍保持不变。
- 缺失值实验说明所在 dtype、统计口径和处理依据；时间实验说明时区、频率、时间单位与窗口边界。用整数最小单位表达示例金额时注明单位。
- 类型、字符串存储后端和可选读写引擎必须明确；依赖变化同步更新 requirements.txt、README.md 和受影响章节，不假定所有读取方式返回相同类型。
- 性能与分块实验先核对结果，再测量有限数据规模；不承诺固定加速倍数，不把 memory_usage 等同于进程峰值内存，说明统计能否跨块合并。
- 使用自制、可检查的小数据；默认不访问在线接口。文本文件、工作簿和 SQLite 连接及时关闭并清理临时产物；实际需要浏览器展示的章节检查页面。
- 来源优先使用与环境匹配的 pandas 官方用户指南和 API 文档。涉及数据库事务、文件引擎或统计结论时，按实际讲解补查对应第一方资料。
- 从空内核顺序执行并保存真实输出；按实际学习目标使用断言。必要异常反例按通用 Notebook 协议独立标记并核对异常类型，读者查看报错后继续下一单元。检查结果只在当次交付说明报告。

- 本课程配套 CSV、Excel 教学输入按约定放在 `date/`，文件名使用二位章节号与英文小写 kebab-case；头部“配套脚本：”注明无外部脚本并列出数据文件与用途。小数组、小表仍优先在单元内构造，生成的临时导出文件不写回 `date/`。
- 辅助学习示意图放在 `image/illustration/`，实际成图与截图放在 `image/`；Notebook 图形输出不要求另存。制作、编号、扩展名与跨章复用遵循[通用图示要求](../../../docs/notebook-protocol.md#图示的制作与整合)。
