## 数组与计算

- 以安装版本对应的 NumPy 官方资料为依据；数学结论另外定位原始论文或权威教材，不用 API 页面替代理论依据。
- 通常使用 np；先用可以手算的小数组，涉及多个轴时尽量采用不相等的轴长度，先解释 shape、轴与广播关系，再引入批量计算或 einsum。
- 按当前目标观察数值、shape、dtype 与内存共享；不能仅凭 base 属性概括全部复制和视图关系。
- 浮点计算说明必要容差；线性代数通过残差、重构或相应关系观察结果，并写明成立条件。默认输入满足条件，不在计算前追加防御性检查。
- 随机实验使用局部 Generator，记录种子与方法；不保证不同版本、算法或后端逐位一致。
- 性能实验先核对结果，再在有限规模下比较；区分数组存储量、中间数组与进程内存，不把单项测量当作完整峰值。

## 数据与运行

- Notebook 工作目录为课程目录。当前落盘教学数据沿用既有 date/，这是明确的存量目录例外；本次协议调整不迁移为 data/。
- 数据文件按章节与用途命名，例如“二位序号-英文主题.csv”；需要 Excel 等格式时说明实际引擎。头部用“数据：”列文件及用途，源码另列“配套脚本：”，没有脚本就省略该项。
- 原始教学数据与生成结果分开，不将临时输出覆盖原始输入；实际创建的文件和句柄按示例流程处理。
- 已确认的首章可作为教学节奏参考，显式协议优先于样章的偶然格式；不把样章中的全部写法上升为必须复制的模板。
