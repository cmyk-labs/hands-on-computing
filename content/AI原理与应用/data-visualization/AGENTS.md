# 数据可视化课程补充协议

全局原则见[根协议](../../../AGENTS.md)，Notebook 与图示规则见 [Notebook 协议](../../../docs/notebook-protocol.md)。范围见 [plan.md](plan.md)，实际依赖、浏览器与运行条件见 [README.md](README.md)，Python 示例参考 [Python 编程规范](../../编程语言/python/Python编程规范.md)。

## 绘图组织特例

- 以一种工具为一章，Vega-Lite 与 Vega-Embed 的配合按规划合讲。本课程逐类绘图可用一个 Code 单元集中写简短的适用场景、数据、核心调用、参数及观察点注释，避免每幅图重复拆出多个 Markdown 单元；概念介绍、复杂交互机制、需要展开的读图分析、章节头尾和纯理论使用相邻 Markdown。
- 比较本身需要多幅图时可以放在同一单元，不机械拆开关联视图。复杂机制按学习步骤展开，不为满足一个单元而堆积代码。
- Python 用实际可执行 Code 单元；JavaScript、JSON 规范和浏览器页面按原生方式展示与运行，不用 Python 包装来掩盖其执行方式。

## 数据与图形

- 使用小型、自制或就地生成的离线数据，说明每条观测、字段、单位和分组；普通图例不临时下载远程数据集。
- Matplotlib 明确 Figure 与 Axes；各库采用对应的显式显示接口，说明 plt.show、display 或 Bokeh show 的作用，不依赖偶然的最后一行隐式输出。
- 科学图默认白底，标题、标签、图例与单位完整；对照图保持必要的坐标、颜色范围和编码一致。误差条与区间解释统计含义，不靠视觉猜测。
- 中文字体按本地可复现条件设置，不用 Notebook 全局 CSS 掩盖字体或图形布局问题；通用辅助示意图和权威原图仍遵循全局图示规则。
- Matplotlib、Seaborn 的导出主题实际检查 PNG 和 SVG 或 PDF；临时导出文件供检查后清理，确需交付的成图归 image/。交互工具可选导出依赖不能默认为已安装或已验证。

## 交互与验收

- 区分 Notebook 输出、独立 HTML、本地资源和 CDN 资源，明确在线条件；声称离线可用时实际检查断开外部资源后的行为。
- 实际操作本章展示的悬停、缩放、图例、选择与回调；对象序列化或 HTML 生成成功不代表交互通过。
- 混合章节分别执行内核部分与浏览器部分。空内核运行不能代替检查 Vega 页面，浏览器成功也不能替代 Python 计算检查。
- Matplotlib、Seaborn 按规划选用图库或案例时，注明实际采用的图形类型和用途；第三方图库只能作为案例参考，知识结论仍有官方或第一方依据。
- 样章与确认使用根协议；前端显示限制、浏览器未测范围和选学导出未执行事项保留在 README 的当前验证说明中。
