# 数据可视化教学补充协议

适用于本目录及子目录。编写前读取[项目协议](../../../AGENTS.md)、[Notebook 编写协议](../../../docs/notebook-protocol.md)和 [Python 编程规范](../../编程语言/python/Python编程规范.md)。章节范围见 [plan.md](plan.md)，环境与运行见 [README.md](README.md)。

- 教学风格与 Python 课程一致。编写前对照[内置类型与运算](../../编程语言/python/02-内置类型与运算.ipynb)和[容器与对象引用](../../编程语言/python/04-容器与对象引用.ipynb)：从小例子解释含义、用法与边界。课程以学会各类图表的绘制与调整为主，综合应用放在基础绘图之后，用于组合已学写法。
- 常用图表逐类讲解，每种图用一个 Code 单元，按“适用场景 → 数据组织 → 最小绘制代码 → 常用参数调整 → 实际成图”组织；说明写成简洁的中文代码注释，参数紧邻对应代码，成图由实际执行产生并显示在单元下方。此项按用户明确要求细化通用七条原则的教学组合方式；注释、输出预期、命名和检查仍遵循通用原则，章节导航、公共概念、交互操作、练习和引用仍可用 Markdown。
- 图表单元先列输入，再写核心绘图调用，接着增加当前图形需要的颜色、坐标、标签、图例或专用参数，最后显示图形；不为展示前后步骤机械重复绘图。复用前文的导入、数据或对象时在注释中点明，不把一个图的数据准备和绘制拆成多个单元；用于比较同一参数或方法的多图可以合放一个单元。
- 按规划覆盖每章必讲内容，选学明确标识。通常一个工具一篇 Notebook；Vega-Lite 与 Vega-Embed 作为特例扩展章合讲，分别承担图表描述与网页嵌入。先完成一张简单图，再逐步增加映射、尺度、样式和交互，不在开篇堆入完整样式框架。
- 特例章按可视化主题归入本课程，明确 JSON 规范、JavaScript 嵌入与 Python 接口的区别；教学组织保持一致，代码按实际语言参考 [JavaScript 编程规范](../../编程语言/javascript/JavaScript编程规范.md)和 [HTML 编程规范](../../Web与应用开发/html/HTML编程规范.md)。浏览器代码在实际页面运行并检查交互，不将 Python 单元执行通过视为浏览器验收。
- 开篇依次单列“学习目标：”“前置知识：”“运行环境：”“环境准备：”“工作目录：”。环境准备链接 README.md，工作目录写“本 Notebook 所在目录；重启内核后从上到下运行”。
- 主知识点使用连续编号二级标题；必要子节使用对应三级标题。正文不使用行内代码高亮；术语或 API 总览表逐行保留原文名称和“中文名称／含义”。
- 每章独立提供导入与小型输入；自制测量数据注明教学模拟，随机实验使用局部 Generator 和固定种子，不下载在线示例数据集。说明每行观测、字段、单位及分组口径。
- 数值和表格观察使用 print()。图形可以使用 plt.show()、IPython.display.display、Bokeh show 等工具要求的展示接口；先解释用途，不依赖单元末尾对象的隐式显示。
- Matplotlib 采用显式 Figure、Axes 写法。图形参数就地解释，先展示最少必要设置，再复用已经介绍的参数；与 Python 课程一致，不增加无关类型标注、类或工程包装。
- 科研图形使用白底、清楚的文字层次和色盲友好配色；同组跨图同色，必要时加点形或线型。轴标签包含变量含义与适用单位，误差条说明统计口径，多图比较核对坐标与颜色范围。
- 中文字体仅选本机确实可用的字体，说明跨平台替换方法并核对缺字；字体配置属于图表本身，不修改 Notebook 正文 CSS。几何和数学图可用清楚的英文或数学标签并在正文解释。
- Matplotlib 与 Seaborn 综合示例练习 PNG 及 SVG 或 PDF 导出。导出文件放入章内说明的临时目录；保留到读者完成查看，并给出关闭与清理方式，不提交临时产物。需要正文外持久引用的实际图片才放 image/。
- 交互章明确内嵌和外部 JavaScript、离线条件及服务依赖；实际检查悬停、缩放、图例、选择或回调。未检查的交互或断网条件不写成通过。Kaleido 静态导出为选学，不作为主线隐含依赖。
- 练习逐题采用“题目 Markdown → Code”，提供输入和注释占位，不使用报错或未定义变量占位。包含图形解释、改变条件和方法选择，至少一题要求说明图形突出或隐藏的信息。
- 最后一个单元为“## 参考与引用来源”，采用“网站／本章参考内容与定位”两列表格，按网站去重并保留版本和直接支持知识点的小节。Matplotlib、Seaborn 两章同时列出规划指定的示例网站和官方图库，明确其用途。
- 每章先在本地草稿确认样板，来源核查和空内核执行通过后整理进本目录；检查真实图形与导出文件，不把代码无报错当作成图验收。
- 并行按单章排队；一个 Notebook 只分配给一名编写者，完成并验收一章即补下一章。协调者维护计划、环境、依赖和共享目录，编写者只修改自己领取的章节及确有需要的配套资源。
