## 理论到实现

- 依据原始论文、作者教材与对应版本官方实现；每项主题在规划中明确理论范围、手写版本、框架对应和检查目标。API 分类不能代替算法学习顺序。
- 算法按“问题与假设 → 符号及必要推导 → 小数据计算 → 手写实现 → 框架实现 → 对照与练习”展开。推导或实现过长时按学习关系拆章，概览不能冒称完成算法教学。
- 手写实现可以使用 NumPy 基础计算与线性代数；正在教学的核心算法不能直接调用现成求解器，解析梯度不能用自动微分代替。框架部分按其真实接口实现。
- 手写训练应包含本章目标所需的迭代、停止和预测流程；一步参数更新不能冒称完整训练。线性 SVM 与核 SVM、树桩与递归决策树等简化版本明确标注能力边界。
- scikit-learn 适用主题以它作为框架对照；PyTorch 只用于规划明确需要的主题，不给全部算法增加一套框架实现。首次使用的重要接口在正文说明。
- 默认数据满足模型已说明的输入条件，不预置形状、范围、缺失值或文件存在性拒绝层。类别分组、树的分裂、收敛停止和算法状态变化是实际逻辑，可使用必要分支。
- 数值稳定变换说明数学作用与成立条件；不能随意加 epsilon、裁剪或捕获异常让错误消失。异常处理与恢复本身是专题时按明确目标展示。

## 公平比较与评估

- 手写与框架对比对齐数据切分、预处理、初始化、dtype、损失求和或平均、截距、正则化、权重与停止条件；说明实现差异可导致的合理偏差，不保证逐位相等。
- 训练、验证与测试边界明确；预处理、特征选择、提前停止、校准及阈值选择只能使用其允许的数据，最终测试集不参与反复调参。
- 说明划分方式、基线、指标含义和搜索预算。无监督任务区分已见数据的结构分析与新输入使用，引用标签评估时说明假设；时间相关数据保持时间关系。
- 随机种子针对实际随机源分别设置，说明线程、设备和算法等复现条件，不把一个 seed 当作控制全部过程。
- 保留并解释收敛警告与实际失败，不批量忽略。模型保存与重载主题检查完整预测流程，不只检查单个估计器可读回。

## 数据与共享模块

- 持久化数据统一在 data/，包括训练图像；区分原始与处理后数据，不覆盖原始输入。外部数据说明来源、许可、字段、单位、目标与版本，模拟数据明确标记。
- 章节配套源码放 scripts/ 对应章节目录；确需跨章导入的模块使用合法 Python 模块路径。命令涉及本课程名称中的 & 时正确引用路径，避免被 shell 解析为运算符。
- 已讲解的读取、划分、评估和绘图流程才可抽取复用，接口和状态明确；当前算法的损失、梯度与核心更新仍在当前章展开。
- 不跨折或跨任务复用已经拟合的预处理状态。导入模块不自动训练、下载或运行实验；当前章显式准备状态。
- 不提交模型权重、大型数据或缓存；保存主题使用明确的临时路径，并说明读取与清理步骤。

## 图形、设备与实际检查

- 按算法目标检查损失轨迹、决策边界、聚类结构或投影等真实成图；动画需有可阅读的静态结果，不能只有播放依赖。
- 模型示意图说明阶段、变体、张量维度、损失及简化条件，不用结构相近的模型图替代当前模型。
- 主线保持普通 CPU 可执行。GPU 专题说明实际框架与设备支持、显存需求及梯度和优化器状态成本，记录实际设备、框架、CUDA、批量与测量范围；未验证写明未验证，不自动切换设备掩盖失败。
- 验收分别核对理论与实现关系、数值结果、框架对照、图形和必要保存重载；完成状态以实际覆盖范围为准，环境安装通过不代表算法章节完成。
